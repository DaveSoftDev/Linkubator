# Linkubator

Aplicación web para la gestión de enlaces en colecciones y etiquetas.

## Estado del proyecto

La documentación funcional fue aceptada el 2026-10-06. Está autorizada su implementación según el alcance y el orden de [roadmap.md](context/roadmap.md); las reglas de producto y las invariantes de esta guía siguen siendo obligatorias.

## Visión

Linkubator permitirá que cada usuario gestione sus propios enlaces y los organice en colecciones y etiquetas.
Las colecciones podrán ser públicas o privadas. Dentro de una colección pública, el usuario decidirá individualmente qué enlaces aparecen en su página pública indexable por buscadores.
